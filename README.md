# syyedmateen.com

Personal site of Syed Mateen: a cinematic WebGL portfolio with original sound. Static HTML, CSS and two small JS bundles. No framework.

`npm run build` writes the finished site to `dist/`. The GitHub Actions workflow (`.github/workflows/main.yml`) builds and deploys it to GitHub Pages on every push to `main`. One-time setting: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

**Adding work needs no code:** upload a video to `content/cgi-ads/` or a certificate to `content/certificates/` and the site rebuilds itself. See [`content/README.md`](content/README.md).

## What's in it

- **No entry gate.** The page opens straight away; the 3D fades in when it's ready.
- **3D stage**: ~16,000 glowing particles re-form into a new shape for each chapter (crystal core, robot, three phones playing your newest CGI ads (picked automatically), lead funnel, workflow, "SAY HELLO"). Between shapes they swirl, run hot, and a chromatic-aberration + glitch pass plays. Solid objects (glass crystal, robot, phones) materialise with a dissolve effect. The phone screens play the preview loops the build makes from `content/cgi-ads/`.
- **Colour switcher**: two-tone Meta Blue (default), Royal Violet, Sunset and Aurora. The whole site and the 3D follow it. Change the default with `DEFAULT_ACCENT` in `src/build.mjs`.
- **Sound**: original music and effects synthesised live in the browser (no audio files, no licences). Whooshes follow the particle transitions; hovers tick; clicks thump. On by default: browsers only allow sound after the visitor's first tap, click or key press, so it starts then. Pages change in place (the next page is fetched and swapped in), so the music carries on across pages without restarting. Any video playing with sound silences the site completely. The intro plays once per visit and muting lasts for that visit.
- Smooth scrolling (Lenis), a metallic arrow cursor (`static/assets/img/cursor*.png`), magnetic buttons, text scramble on headings, robot logo (`mark()` in `src/build.mjs`).
- Videos in device frames (phone frames for ads, screen frames for demos) that follow each video's real shape, a full-screen lightbox that fits vertical and wide videos, a CGI ads carousel, a certificates wall, three case-study pages, SEO/AEO/LLM layer (JSON-LD, video sitemap, robots.txt for AI crawlers, llms.txt).
- Phone menu (with the colour picker inside it on small screens).
- Phones get fewer particles; slow devices drop the glow automatically; reduced-motion settings are respected.

## SEO, AEO and GEO

- Every page has its own title, description, canonical URL, share image (`static/assets/img/og/`, re-render with `python3 tools/og/og.py`) and JSON-LD (Person, ProfessionalService, WebSite, Service, VideoObject, FAQPage, BreadcrumbList, Article).
- Each CGI ad has its own watch page in `/ads/` so Google can index the videos.
- `sitemap.xml` lists every page with its images and videos. `robots.txt` welcomes search engines and AI crawlers. `llms.txt` and `llms-full.txt` give AI assistants a clean summary and the full text.
- To verify the site in Google Search Console or Bing Webmaster Tools, paste the code into `GOOGLE_VERIFICATION` / `BING_VERIFICATION` at the top of `src/build.mjs`, rebuild and push, then submit `https://www.syyedmateen.com/sitemap.xml`.

## Common edits

- **Add a CGI ad:** upload the video to `content/cgi-ads/`. Done. (Optional `.jpg` cover and `.json` details with the same name.)
- **Add a certificate:** upload the image or PDF to `content/certificates/`. Done.
- **Change the ads on the 3D phones:** they show the first three ads; add `"pin": true` to an ad's `.json` to bring it forward, or `"phone": false` to skip one.
- **Swap a tile video:** replace the MP4 in `static/assets/video/` with the same name (see `VIDEO-KIT.md`).
- **Testimonials:** hidden for now (`SHOW_EXAMPLE_QUOTES = false`). Put real quotes in `quotes` in `src/build.mjs`, remove the "Example only" label and set it to `true`.
- **Add WhatsApp:** set `WHATSAPP` at the top of `src/build.mjs`.

## Run it locally

```
npm install
npm run build
npx serve dist
```

The build needs ffmpeg for the media (installed by `npm install` through `ffmpeg-static`) and, for PDF certificates, `pdftoppm` (poppler-utils; the GitHub workflow installs it). Processed media is cached in `.cache/`, so rebuilds only handle new files.
