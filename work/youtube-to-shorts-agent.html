Case 02 · Automation · Content

One YouTube link in. Captioned, scheduled Shorts out.

Generating Shorts is the easy part. This agent automates everything around them.

In short

You send the agent a YouTube URL and the number of Shorts you want. It extracts the strongest clips, adds captions, generates the Shorts through Klap, checks the processing, calculates publishing times, uploads to the connected platforms and sends a summary on Telegram.

The problem

Turning one long video into Shorts by hand means downloading it, finding timestamps, writing every caption and uploading to each platform one by one.

How it works

  1. Send the inputA YouTube URL and the number of Shorts.
  2. Clips are extractedThe agent picks the important moments.
  3. Captions are added
  4. Shorts are generated through KlapProcessing is checked before anything moves on.
  5. Publishing times are calculated
  6. Content is uploadedTo each connected platform.
  7. A Telegram summary comes back

Why it matters

The interesting part isn't generating Shorts. It's automating the whole workflow around them. Send the video, and the agent handles the rest.
